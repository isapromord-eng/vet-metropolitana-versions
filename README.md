# VetMetro RD - Multiple Landing Page Versions

Multiple SEO-optimized landing page versions for Clínica Veterinaria Metropolitana (VetMetro RD) with different design approaches for client presentation.

## 🎯 Purpose

This monorepo contains multiple versions of landing pages for VetMetro RD, each with a unique design approach and optimization strategy to provide the client with various options to choose from.

## 📁 Structure

```
vet-metropolitana-versions/
├── v1-original/           # Original version (professional, clean)
├── v2-editorial/          # Editorial/glamour style (magazine-like)
├── v3-tech/               # Tech/modern style (gradients, glassmorphism)
├── v4-minimal/            # Minimalist/luxury style (whitespace, elegant)
└── v5-interactive/        # Interactive/wow factor (3D, scroll effects)
```

## 🎨 Version Features

### v1-original ✅
- **Style**: Professional and clean
- **Features**: Complete booking system, WhatsApp integration, services catalog
- **SEO**: Full optimization with meta tags, Open Graph, structured data
- **Status**: Ready for deployment

### v2-editorial (Coming Soon)
- **Style**: Editorial/glamour, typography-heavy
- **Target**: High-end clientele, luxury feel
- **Wow Factor**: Magazine-style layouts, elegant typography

### v3-tech (Coming Soon)
- **Style**: Tech startup aesthetic, modern gradients
- **Target**: Modern pet owners, tech-savvy clients
- **Wow Factor**: Glassmorphism, smooth animations, micro-interactions

### v4-minimal (Coming Soon)
- **Style**: Minimalist luxury, premium whitespace
- **Target**: Sophisticated clients, clean aesthetics
- **Wow Factor**: Subtle animations, focus on content

### v5-interactive (Coming Soon)
- **Style**: Highly interactive, dynamic experiences
- **Target**: Impressive visual impact, memorable experience
- **Wow Factor**: 3D elements, scroll-triggered animations, parallax

## 🚀 Common Features Across All Versions

- ✅ **SEO Optimization**: Meta tags, structured data, Core Web Vitals
- ✅ **Booking System**: Appointment scheduling functionality
- ✅ **CRM Integration**: Lead capture and management
- ✅ **Responsive Design**: Mobile-first approach
- ✅ **Performance**: Optimized loading times
- ✅ **Social Integration**: WhatsApp, social media sharing
- ✅ **Deployment Ready**: Netlify/Vercel configuration

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: GSAP + Framer Motion
- **Icons**: Lucide React

## 📦 Installation

Each version can be installed and run independently:

```bash
cd v1-original
npm install
npm run dev
```

## 🏗️ Build

```bash
npm run build
```

## 🌐 Deployment

Each version can be deployed independently to Netlify or Vercel using the provided configuration files.
